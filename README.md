# Gateway-IoT

Gateway-IoT 是一个基于IMX6ULL平台的物联网网关项目，用于管理和处理物联网设备数据。

## 项目特点

- 多线程架构：使用线程池管理并发任务
- 看门狗机制：实现组件健康监控和自动恢复
- 数据持久化：使用SQLite数据库存储设备数据
- 日志系统：支持多级别、多目标的日志记录
- LoRa通信：支持与LoRa设备进行数据交互
- Socket通信：提供TCP/IP接口服务

## 系统架构

### 核心组件

1. 线程池（Thread Pool）
   - 动态任务分配
   - 可配置线程数量
   - 任务队列管理

2. 看门狗（Watchdog）
   - 组件健康监控
   - 自动故障恢复
   - 可配置检查间隔和重启策略

3. 日志系统（Logger）
   - 多级别日志：DEBUG、INFO、ERROR、FATAL、TRACE、WARN
   - 多目标输出：控制台、文件、系统日志
   - 文件自动轮转

4. 数据节点管理
   - 环境数据采集
   - 数据缓存队列
   - SQLite持久化存储

### 通信接口

1. LoRa通信
   - 设备数据接收
   - 命令下发
   - 自动重连机制

2. Socket服务
   - TCP/IP服务器
   - 客户端连接管理
   - 数据查询接口

## 编译与运行

### 依赖组件

- SQLite3
- pthread
- gcc  
- 交叉编译工具链 arm-linux-gnueabihf-gcc
